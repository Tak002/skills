# example-skill

새 스킬을 만들 때 어떤 모양이어야 하는지 보여 주는 자리표시자다. 실제 작업은 하지 않는다.

## 실행 절차

1. 사용자에게 이 파일이 예시라는 점을 알린다.
2. `templates/SKILL.md` 를 복사해 새 스킬을 시작하라고 안내한다.
3. 작성 규칙은 저장소 루트의 `AGENTS.md` 를 가리킨다.

## 주의

- 이 스킬을 실제 작업에 쓰지 않는다.
- 첫 번째 진짜 스킬이 추가되면 이 폴더는 지워도 된다.
