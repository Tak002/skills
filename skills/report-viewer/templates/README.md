# {{TITLE}} 사용법

이 폴더는 보고서·정리 문서를 모아 두는 곳입니다. 파일을 넣고 뷰어로 봅니다.

## 보는 방법

| 방법 | 언제 |
|---|---|
| **`start.cmd` 더블클릭** (mac/Linux 는 `start.sh`) | 평소. 로컬 서버가 뜨고 브라우저가 열립니다. 파일을 넣으면 새로고침만 하면 보이고, 창을 다시 클릭해도 자동으로 다시 읽습니다. 상단의 **➕ 폴더 추가**로 PC 안의 다른 폴더도 볼 수 있습니다. |
| `index.html` 더블클릭 | 서버 없이 볼 때. 색인 파일(`_viewer/data.js`)이 필요합니다. Claude Code 훅이 자동으로 만들고, 직접 만들려면 `python _viewer/build.py`. Chrome/Edge 라면 **📂 폴더 열기**로 색인 없이 폴더를 직접 읽을 수도 있습니다. |

서버는 이 PC(127.0.0.1)에서만 접속됩니다. 검은 창을 닫으면 서버가 꺼집니다. 로그인 때 자동으로 띄우려면 `start.cmd` 의 바로가기를 `shell:startup` 폴더에 넣으면 됩니다.

## 파일 규칙

- 파일명: `YYYY-MM-DD-주제.md`. 날짜가 앞에 오면 정렬과 날짜 인식이 됩니다.
- 앞부분에 front matter 를 넣으면 제목·날짜·태그가 목록에 표시됩니다.
  ```yaml
  ---
  title: 9월 첫째 주 주간 보고
  date: {{TODAY}}
  tags: [주간보고, 프로젝트A]
  math: true     # $...$ 인라인 수식을 쓸 때만
  ---
  ```
- `README.md` 를 폴더에 두면 그 폴더 화면 아래에 설명으로 렌더링됩니다.

## 뷰어가 보여 주는 것

| 형식 | 표시 |
|---|---|
| md | GitHub 스타일. 표, 체크리스트, 코드 하이라이트(언어 지정), ```` ```mermaid ```` 다이어그램, `$$ $$` 수식, 자동 목차, 문서 간 상대 링크 |
| html | 그대로 표시 (CSS/JS 를 안에 넣은 단일 파일 권장). "새 탭에서 열기" 로 원본 열람 |
| json | 접을 수 있는 트리 + 하이라이트된 텍스트. 최상위 `"title"` 이 있으면 제목으로 사용 |
| txt, log | 줄 번호 텍스트, 줄바꿈 토글 |
| py, js, ts, c, cpp, java, cs, go, rs, sql, sh, ps1, yaml, xml, css … | 줄 번호 + 문법 강조 |
| pdf, 이미지, docx, xlsx, csv … | 첨부 링크 |

검색은 상단 검색창 또는 `/` 키. 🌙 로 다크 모드. `Ctrl+P` 로 본문만 인쇄.

## 설정

- `_config.json`: 제목, 포트, 폴더 분류. 바꾼 뒤 서버를 다시 띄웁니다.
- `_roots.json`: 뷰어에 등록한 다른 폴더 목록 (뷰어가 관리).
- `_viewer/`, `index.html`, `start.*`: 뷰어 본체. report-viewer 스킬이 관리하므로 직접 고치지 않습니다.
